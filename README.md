# Прототип управления шардами

Интерактивный интерфейс на React, TypeScript и Vite. Все данные находятся в памяти браузера; сервер приложения, база данных и внешние API не используются. Перезагрузка страницы восстанавливает исходное состояние.

## Локальный запуск

В подготовленном рабочем каталоге можно запустить `./run.sh`. Скрипт использует установленный Node.js или временную копию, подготовленную для проверки в этой среде.

Нужен Node.js 22.12+ (или 24 LTS) и npm.

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно http://127.0.0.1:5173).

```sh
npm run build     # проверка TypeScript и production-сборка
npm run preview   # просмотр собранного приложения
```

## Демонстрация

- 12 групп G01–G12, 36 экземпляров, изначально по 4 мастера в каждом ЦОД.
- Поиск: `G01`, `G0` или точный номер `2`, `№2`, `#2`. Поиск сочетается с фильтром «Только проблемные». Сводка всегда охватывает всю систему.
- Кнопка «Открыть G01» сразу открывает группу для демонстрации. Строки таблицы также открывают панель; с клавиатуры используйте кнопку с ID группы.
- Для переключения выберите доступную реплику с отставанием не более 1000 мс и подтвердите маршрут. Симуляция длится 2,4 секунды. Закрытие панели не прерывает операцию.
- Сценарии отставания и недоступности изменяют реплику №2 в G01; реплика №3 остаётся доступной для переключения. Каждый сценарий заново загружает данные и очищает историю.
- Флажок ошибки применяется только к следующей запущенной операции. Ошибка происходит на проверке, до изменения ролей; повторная попытка доступна. Отмена выбора не расходует флажок.
- Пока идёт операция, переключения, сценарии, флажок ошибки и сброс заблокированы. История создаётся при старте и обновляется при завершении.
- «Сбросить демо» восстанавливает данные, очищает историю, поиск и фильтр, выключает ошибку и закрывает панель.

Недоступный мастер сохраняет роль и блокирует плановое переключение. Отдельный сценарий недоступности мастера не добавлен, в соответствии с заданием.
