# Прототип управления шардами

Интерактивный интерфейс на React, TypeScript и Vite для демонстрации операций с мастерами и репликами. Все данные находятся в памяти браузера; сервер приложения, база данных и внешние API не используются. Перезагрузка страницы восстанавливает исходное состояние. Все операции — симуляция.

## Локальный запуск

Можно запустить `./run.sh`: он использует установленный Node.js (или временную копию в этой среде) и установит зависимости, если они отсутствуют.

Нужен Node.js 22.12+ (или 24 LTS) и npm.

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно http://127.0.0.1:5173).

```sh
npm run build     # проверка TypeScript и production-сборка
npm run preview   # просмотр собранного приложения
```

## Структура проекта

- `src/model.ts` — демо-данные, сценарии и правила допустимости переключений и перемещений.
- `src/main.tsx` — интерфейс, состояние React, симуляция операций и история текущей сессии.
- `src/styles.css` — оформление и адаптация интерфейса.
- `AGENTS.md` — краткий ориентир для агентов, работающих с кодом.

## Демонстрация

- Мелкие шрифты (исходно 12–14 px) увеличены на 4 pt. Номера экземпляров отображаются минимум двумя цифрами (№01, №02, …, №10), в том числе в выборе мастера, уведомлениях и истории; поиск принимает номера с ведущим нулём и без него. Весь интерфейс использует моноширинный шрифт: обозначения ЦОД, групп и ролей, доступность, отставание, числа, поля выбора и кнопки отображаются одинаково во всех разделах.
- Цвета ЦОД основаны на [палитре Ubuntu](https://design.ubuntu.com/brand/colour-palette): A — тёмный оранжевый с коричневым оттенком (#A33B16, затемнённый Ubuntu orange), B — баклажановый, C — тёплый серый. Фоны светлые, акценты цветные; обозначение реплики нейтральное с контуром, предупреждения жёлтые. Цвета повторяются в заголовках таблицы, полях выбора исходного и целевого ЦОД и вариантах нового мастера при одиночном переключении; буквенные обозначения ЦОД сохраняются.
- 12 групп G01–G12, 36 экземпляров, изначально по 4 мастера в каждом ЦОД. У реплик любой группы можно включать и отключать репликацию. Отключённая реплика не подходит для переключения мастера.
- Поиск: `G01`, `G0` или точный номер `2`, `№2`, `#2`. Поиск сочетается с фильтром «Только проблемные». Сводка всегда охватывает всю систему.
- Кнопка «Открыть G01» сразу открывает группу для демонстрации. Строки таблицы также открывают панель; с клавиатуры используйте кнопку с ID группы.
- Для переключения выберите доступную реплику с включённой репликацией и отставанием не более 1000 мс и подтвердите маршрут. Каждый этап симуляции длится случайное время от 3 до 7 секунд: проверка, отключение старого мастера, применение изменений репликации, включение нового мастера и завершение. Широкая панель группы показывает три экземпляра слева и ход переключения или изменения репликации справа; на узком экране блоки идут друг под другом. Закрытие панели не прерывает операцию.
- Для массового перемещения сначала выберите исходный ЦОД, затем отдельно укажите целевой ЦОД для каждого его мастера. Можно распределить мастеров между двумя другими ЦОД; исходный ЦОД недоступен как назначение. Кнопка запуска доступна только после выбора всех назначений и успешной проверки каждой группы. Смена исходного ЦОД, загрузка сценария и сброс очищают назначения. Прогресс и история сохраняют маршрут каждой группы. Сначала проверяются все затронутые группы; если хотя бы одна целевая реплика не подходит, состояние групп не меняется. Затем группы перемещаются по очереди, и для активной группы показаны те же пять этапов и состояния, что при одиночном переключении; каждый этап длится от 3 до 7 секунд. Роль мастера меняется после завершения этапов группы. Мастера других ЦОД остаются на месте.
- Сценарии отставания и недоступности изменяют реплику №02 в G01; реплика №03 остаётся доступной для переключения. Каждый сценарий заново загружает данные и очищает историю.
- Флажок ошибки применяется только к следующему одиночному переключению мастера. Ошибка происходит на проверке, до изменения ролей; повторная попытка доступна. Отмена выбора не расходует флажок.
- Включение и отключение репликации — симуляция с этапами предварительной проверки, публикации карты распределения и проверки после изменения. Каждый этап длится случайное время от 3 до 7 секунд. Состояние реплики меняется на этапе публикации карты. Панель сохраняет все этапы и результат после завершения операции, как при переключении мастера; при запуске следующей операции справа показывается только её ход. Пока идёт любая операция, переключения, управление репликами, массовое перемещение, сценарии, флажок ошибки и сброс заблокированы. История создаётся при старте и обновляется по ходу операции.
- «Сбросить демо» восстанавливает данные, очищает историю, поиск и фильтр, выключает ошибку и закрывает панель.

Недоступный мастер сохраняет роль и блокирует плановое переключение. Отдельного сценария недоступности мастера нет.

## Проверка массового перемещения

Список выбора целевых ЦОД для мастеров расположен в одну колонку на всех размерах экрана.

Выберите ЦОД A и задайте разные назначения для G01, G04, G07 и G10. До выбора всех четырёх назначений запуск недоступен. После завершения каждый мастер должен находиться в выбранном ЦОД; мастера остальных групп остаются на месте, маршруты видны в прогрессе и истории. В сценариях отставания и недоступности назначение G01 в ЦОД B блокирует весь план; выбор ЦОД C позволяет продолжить. Проверьте очистку назначений при смене источника, загрузке сценария и сбросе, а также отсутствие горизонтальной прокрутки блока перемещения на узком экране.
